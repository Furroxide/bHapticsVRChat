# Changelog

## [2.3.1] - 2026-07-18

### Added
- Automated GitHub releases from `main` with `bHapticsOSC.exe` and `bHapticsOSC-VRChat.unitypackage` assets.
- Release metadata validation for pull requests targeting `main`.
- VRCFury-based avatar setup and punch impact haptics support.
- Furroxide maintainer credit in the VRChat radial menu and control panel, with a GitHub profile link in the control panel.

### Changed
- Release builds now preserve the direct single-file `bHapticsOSC.exe` download.
